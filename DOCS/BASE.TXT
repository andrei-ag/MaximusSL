                            Maximus Script Language
          Скриптовый язык для работы с базой пользователей Maximus BBS

                   Copyright 2001 MOST NEEDFUL THINGS [MNT]


  О программе

   Компилятор знает о базе пользователей только одну вещь - размер информации
 о одном пользователе (460 байт). Те параметры, с которыми вам придется
 работать, нужно задавать в самом скрипте.

   Некоторые параметры представлены в виде типов, с которыми компилятор может 
 работать только через специальные команды. Этих команд несколько и запомнить
 для чего необходима, каждая - не так тяжело.

  Работа с базой - открытие

   Место нахождение базы пользователей (как и любого другого файла) задается в 
 самом скрипте. Путь (включая и имя) может быть фиксированным или переменным.

   Имя файла, с которым нужно работать будет использоваться один раз, при 
 открытии. Далее работая с открытым файлом нужно только знать его файловый номер,
 значение которого будет установлено после открытия, и не должно изменяться ни
 при каких обстоятельствах.
   Файловый номер, что-то вроде порядкового номера, для каждого открытого файла. 
 Знание файлового номера, позволяет работать одновременно с несколькими файла.
 Номер должен храниться в переменной типа integer.

 Пример использования фиксированного пути к базе пользователей:

   integer handle;
   fopen('user.bbs',handle);
   if (handle != -1) @continue;
    write('Ошибка открытия файла "user.bbs"!\n')
    exit;
   :@continue;
   ...
   fclose(handle);

   В этом куске скрипта, переменная "handle" будет использована в для хранения 
 файлового номера "user.bbs" (который должен располагаться в одном каталоге со
 скриптом). Командой "fopen" файл "user.bbs" будет открыт. Если по какой-то из
 причин файл небыл открыт, переменная отведенная для хранения файлового номера
 будет содержать "-1".

   Пример использования переменного пути:

   integer base_no;
   string base_name;
   write('Введите полный путь (включая имя файла) к базе пользователей: ');
   read(base_name);
   fopen(base_name,base_no);
   if (base_no != -1) @continue;
    write('Ошибка открытия файла ',base_name,'!\n')
    exit;
   :@continue;
   ...
   fclose(base_no);

   В этом примере файловый номер будет содержаться в переменной "base_no". Имя 
 файла переменное (зависит от ввода пользователя), оно будет храниться в
 переменной "base_name" (тип string).

*  После проведения всех необходимых операций над любым файлом, не забывайте 
 закрыть его.

  Параметры пользователя, изменение

   Для того, что бы какой-то из параметров был доступен для работы (изменения, 
 проверки), нужно присвоить ему имя и параметры, а затем загрузить в память.
 Для этого существует специальная команда "define".

   Формат команды: "define user_x [x,t];"

   После названия команды ("define"), должно идти название параметра 
 пользователя, по которому в скрипте вы будете обращаться к определенному
 параметру пользователей. В квадратных скобках, через запятую должны быть
 перечислены параметры - смещение и тип.

   Смещение это смещение параметра относительно начала карточки (например, для 
 имяни смещение равно 0, а для года рождения 136). Тип - число (тип числа byte
 short, integer, real) или строка (string), тип определяется из размера
 параметра: 1 байт - byte, 2 байта - integer, 4 байта - real, больше четырех -
 строка.

   Типы переменных: 0 - integer (2 байта)
                    1 - real (4 байта)
                    2 - string (до 255 байт)
                    любое число - byte (1 байт) или спец. структура ("+")

   Примеры задания параметров:

   define user_name [0,2];    ; имя пользователя
   define user_alias [404,0]; ; уровень доступа

   Параметры помеченные символом "+", а так же byte - это специальные типы, 
 работать с которыми можно только через специальные команды (смотри ниже
 "Специальные типы").

  Глобальные команды, для работы с пользователями (удаление, изменение)

   Для работы с пользователями необходимо открыть базу пользователей, задать 
 параметры карточки (с помощью команды "define"), которые будут использоваться
 в скрипте. А затем воспользоваться одной из глобальных команд "rd_user",
 "wr_user" или "dl_user".

   Если нужно изменить или просто вывести какой-то параметр пользователя, 
 сначала нужно прочитать данные о пользователе. Например:

   integer handle;               ; handle - переменная под файловый номер базы
   string  user_bbs;             ; user_bbs - переменная под путь к базе
   read(user_bbs);               ; считаем путь к базе
   fopen(user_bbs,handle);       ; откроем базу, файловый номер в "handle"
   if (handle = -1) @er_open;    ; если файл не открылся, выйдем
   integer n;                    ; n - переменная для хранения длины прозвища
   define user_name [0,2];       ; имя пользователя (0 - смещение, 2 - тип)
   define user_alias [72,2];     ; прозвище (72 - смещение, 2 - тип (строка))
   define user_priv [404,0];     ; уровень доступа (404 - смещение, 0 - тип)
   rd_user(handle,1);            ; прочитаем из файла с файловым номером
   ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;; хранящемся в "handle", пользователя номер 1
   write(user_name,' ');         ; выведем на экран имя
   str_len(user_alias,n);        ; рассчитаем длину прозвища и сохраним в "n"
   if (n = 0) @close_file;       ; если прозвище не указано, не выводим его
    write('"',user_alias,'"');   ; выведем прозвище на экран
   :@close_file;
    write('\n');                 ; перевод каретки
    user_name = 'sucker';        ; изменим имя пользователя 1 на 'sucker' :))
    user_priv = 0;               ; установим уровень "twit" :-)
    wr_user(handle,1);           ; запишем измененные параметры 1 пользователя
    fclose(handle);              ; закроем базу пользователей
    :@er_open;
     exit;                       ; выход

   Параметры у трех команд одинаковые. Хочу напомнить, что можно дублировать 
 пользователей - например, считать пользователя номер 1, изменить какие-нибудь
 параметры (не обязательно) и записать в пользователя номер 2.

  Специальные типы параметров карточки и работа с ними

   Компилятор не знает типов значений, которые используются в карточке. Он не 
 умеет работать (например) с числом, состоящим их одного байта или со
 специальной структурой, в которой хранятся дата и время. Для этого написаны
 специальные команды, которые позволяют перевести данные в переменные типов,
 с которыми компилятор может работать (например, байт в integer или real).

   Для перевода из байта в переменную типа integer или real (по выбору) 
 существует команда "byte_to_num(x,y)". Где первый параметр (x) это название
 параметра в базе, в котором находится байт. Второй это название переменной, в
 которую нужно положить переведенное число.

   Проведя какие-то желаемые модификации, нужно перевести число в байт и 
 положить обратно в параметр, для этого есть функция int_to_byte(x,y).
   Икс (x) это название параметра в базе, в который нужно положить значение из
 переменной y (обязательно типа integer). Хочется выделить то, что перевод
 значения в байт может быть произведен только из переменной типа integer.

   Максимус умеет хранить дату и время всего в четырех байтах (вместо ожидаемых 
 шести). Такой формат хранения, используется в таких парамерах как "дата
 последнего звонка (192)", "дата последней проверки новых файлов (240)" и прочих.
 Функция "date_to_num(x,1,2,3)" конвертирует указанные параметры (указанной)
 структуры в переменные типов integer или real (по желанию).

   Пример работы программы:

   string mo='xx';
   integer handle,da,yr;
   define user_last[192,0];
   string filename='user.bbs';
   fopen (filename,handle);        ; Читаем первого пользователя.
   rd_user(handle,1);
   date_to_num(user_last,da, ,yr); ; Переводим дату (кроме месяца) его
                                   ; последнего звонка в переменные типа integer
   yr=yr+1980;                     ; Конвертируем год, для вывода
   write('Дата последнего звонка: ',da,'/',mo,'/',yr);
   fclose (handle);
   pause;
   exit;

  Примеры скриптов

   Каталог "TEST" содержит скрипты, которые могут служить примерами (учебником) 
 для написания своих и (или) показателем мощности языка. В каталоге есть
 скрипты работающие с базой, файлами данных, файлами отчетов и прочие.

   Скрипты серии "del_00?.msl", работают с базой пользователей. С номером (0-2 
 вместо ?) возможности возрастают. Если первый просто рассчитывает количество
 дней, которое первый пользователь не звонил, то последний ("del_002.msl")
 удаляет пользователей нарушивших определенные условия и ведет в текстовом
 файле, отчет о проделанных изменениях в базе.

   Скрипты "unpak" и (а особенно) "pak" показывают возможность работы MSL с 
 файлами (ресурсов) данных. Если у языка хватает возможностей, для работы с
 файлами-ресурсами для игр, то я думаю, что их хватит для работы с базой и
 файлами отчетов.
