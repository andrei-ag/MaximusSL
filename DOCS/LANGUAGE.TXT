          Скриптовый язык для работы с базой пользователей Maximus BBS

  Описание языка

   Перед написанием скриптов необходимо подробно ознакомиться с командами языка
 и его синтаксисом, а так же посмотреть примеры написанных скриптов (каталог 
"examples").

   Занимаясь разработкой и отладкой любого скрипта, не старайтесь написать его
 "сразу", написав какой-то из кусков кода, обязательно проверьте правильно ли
 он исполняется компилятором!

   При разработке и отладке любого скрипта нужно всегда помнить, что в одной
 строке может содержаться только одна команда (метка тоже считается за команду)
 и что каждая команда (и соответственно строка) должна обязательно
 заканчиваться точкой с запятой. Весь текст должен быть заключен только в 
 одинарные скобки "'", двойные (") в языке не используются.

 ------------------------------------------------------------------------------

  Типы данных (integer, real, string)

   Компилятор может работать только с тремя типами данных, количество
 переменных каждого типа не должно превышать 100.

   Integer - целое число от -32.768 до 32.767
   Real    - целое число от -2.147.483.648 до -2.147.483.647
   String  - строка, может содержать от 1 до 256 символов

   Переменные задаются примерно так:

    integer number = 1000;
    real long = -103921;
    string str = 'mql';

   Указывать начальное значение переменной любого типа не обязательно. Можно
 объявлять несколько переменных одного типа в одной строке, для этого нужно
 отделять имена переменных запятой. При объявлении так же можно присваивать
 переменным начальные значения. Например:

   integer one=1,two=2,minus_one_hundred=-100;
   string yes='yes',no='no',yes_or_no;

                                     * * *

  Метки

   Метка задается символом двоеточия, перед ее именем. После имени не должно
 быть никаких лишних символов, только маркер конца имяни ";".

*  Метки заданные ":label_1;" и ": label_1;" не будут считаться идентичными!
*  Длина имени не долна привышать 20 байт.

   Пример метки: ":label_1;" (задана метка с именем "label");

                                     * * *

  Вывод данных на экран (команда write)

   Команда "write" отвечает за вывод различных данных на экран. Команда может
 выводить сочетание текста со значениями переменных.

   Пример использования write: integer a = 2 * 10;
                               write('2 * 10 = ',a);
   На экран выведется текст из кавычек, а затем значение переменной a (20).

   Если нужно вывести текст и значения переменных, то участки должны разделяться 
 запятыми, например: "write(num,'text1',str,'text2',a,'\n');".

                                     * * *

  Ввод данных (команда read)

   Команда "read" считывает данные в одну или несколько переменных.

   Пример использования read: "read(number,str);"
   Сначала считывается значение в переменную number (до первого нажатия клавиши 
 Enter), каретка переводится на следующую строку и считывается значение в
 переменную str.

   Если нужно ввести значение в несколько переменных, их имена должны 
 указываться (в скобках) через запятую.

                                     * * *

  Сравнение переменных (команда if)

   Команда "if" сравнивает значения двух переменных одинакового типа, числа и 
 значения переменной или два числа, и если условие выполняется, переходит на
 строку к указанной метке.

   Пример использования if: "if (num1 != num2) @not_eq;"
   Если значение переменной "num1" не равно значению переменной "num2",
 переходим к метке "@not_eq".

   Знаки сравнения:        ">" - больше  ">=" - больше или равно
                           "<" - меньше  "<=" - меньше или равно
                           "=" - равно   "!=" - не равно

   Разделительные символы: "|" - или     "&" - и

   Разделительные символы используются тогда, когда необходимо проверить 
 несколько условий. В вызове команды "if" должен использоваться только один тип
 разделителя, комбинировать их (пока) нельзя.

   Пример использования: "if (num = 3 | num > 3) @eq_or_jg;"
   Синоним больше или равно: если значение переменной "num" равно 3 ИЛИ больше 
 3, перейдем к метке:

   Второй пример: "if (num != 1 & num != 2 & num != 100) @the_end;"
   Если значение переменной "num" не равно 1 И не рано 2 И не равно 100, 
 перейдем к метке.

   После имяни метки не должно быть никаких лишних символов (например пробелов), 
 имя метки должен завершать символ ";"!

                                     * * *

  Безусловный переход на строку (команда go to)

   Команда "go to" переходит на строку к указанной метке, оттуда компилятор  
 продолжает выполнение команд.

   Пример использования go to: "go to @loop;"
   Компилятор переходит к метке "@loop".

   После имени метки не должно быть никаких лишних символов (например, 
 пробелов), имя метки должен завершать символ ";"!

                                     * * *

  Цикл "for"

   Стандартный цикл for (а/ля C/C++).

   Пример использования for: for (i=0; i>=m; i=i+1)
                             write(j,'\n');
                             end_for;

   Цикл исполняется пока значение переменной "i" не станет больше или равным  
 значению переменной "m" (условие не выполниться). В начале цикла значение
 "i" равно нулю, при каждом исполнении цикла значение "i" изменяется на
 единицу, если условие выполнилось значение "i" не будет изменяться.

   Тело цикла начинается после for и до метки "end_for", которая обозначает  
 конец тела цикла.

   Можно задавать бесконечный цикл (без условия), для этого в теле условия нужно 
 указать один символ "#". Выход из бесконечного цикла осуществляется с помощью
 команды "break", после нее обязательно должен идти переход к концу цикла -
 команде "end_for". Пример такого цикла можно посмотреть в скрипте из каталога
 примеров - "pak.msl".

  Пауза (команда "pause")

   Компилятор ждет нажатия любой клавиши, после этого он продолжает выполнение
 скрипта.

  Открытие, создание файлов (команды "fopen" и "fcreate")

   Команда открывает  или создает указанный файл для чтения и записи. Обе
 команды имеют одинаковые параметры.

   Примеры использования fopen: "fopen('c:\autoexec.bat',handle);"
                                "fopen(filename , file);"
   В первом случае будет открыт файл "c:\autoexec.bat", файловый номер этого 
 файла будет лежать в переменной "handle". Во втором случае будет открыт файл,
 имя которого будет содержать переменная filename, файловый номер будет лежать
 в переменной "file".

   Если при открытии файла произошла ошибка, значение файлового номера будет 
 равняться "-1".

   Имя файла (путь к файлу и непосредственно его имя) должны располагаться в 
 одинарных кавычках (') или в переменной типа string.

   Файловый номер должен храниться в переменной типа integer! Параметры команды 
 должны отделяться друг от друга запятой!

   Сначала считывается значение в переменную number (до первого нажатия клавиши 
 Enter), каретка переводится на следующую строку и считывается значение в
 переменную str.

                                    * * *

  Чтение данных из файла (команда "fread")

   Команда читает из открытого файла определенное количество байт, в указанную 
 переменную.

   Пример использования fread: "fread(handle,buf,3);"
   Из ранее окрытого файла, с файловым номером, хранящимся в переменной "handle"
 будет прочитанно 3 байта в переменную "buf". Данные будут считанны из позиции 
 на которой сейчас находиться указатель (смотри команду fseek).

   Количество байт для чтения может быть указано в виде цифр или храниться в 
 переменной типа real. Все параметры команды должны разделяться запятыми.

   Вместимость переменных:  integer - 2 байта
                            real    - 4 байта
                            string  - от 1 до 256 байт

   В переменную типа "integer" можно считать только два байта, не больше ни 
 меньше! То же касается и с переменной типа "real" (можно считать 4 байта). В
 переменную string нельзя считать меньше 1 и больше 256 байт.

                                    * * *

  Запись данных в файл (команда "fwrite")

   Команда записывает в открытый файла определенное количество байт, из 
 указанной переменной.

   Пример использования fwrite: "fwrite(handle,string,str_size);"
   В ранее окрытый файл, с файловым номером, хранящимся в переменной "handle",
 будет записано количество байт хранящееся в переменной "str_size" (типа real) 
 из буффера "string" (типа "string"). Данные будут записаны в позицию, на
 которой сейчас находиться указатель (смотри команду fseek).

   Количество байт для чтения может быть указано в виде цифр или храниться в 
 переменной типа real. Все параметры команды должны разделяться запятыми.

   Вместимость переменных:  integer - 2 байта
                            real    - 4 байта
                            string  - от 1 до 256 байт

   Из переменной типа "integer" можно записать только два байта, не больше ни 
 меньше! То же касается и с переменной типа "real" (можно записать 4 байта).
 Из переменной string нельзя записать меньше 1 и больше 256 байт.

                                    * * *

  Перемещение указателя (команда "fseek")

   Команда перемещает указатель в указанном файле, на указанную позицию.

   Пример использования fread: "fseek(handle,0,2);"
   В ранее окрытом файле, с файловым номером, хранящимся в переменной "handle" 
 будет перемещен указатель с конца файла на 0 байт (т.е. указатель будет
 находиться в позиции конца файла).

   Смещение и тип перемещения указателя могут быть указанны в виде цифр или 
 храниться в переменных. Смещение может храниться только в переменной типа real,
 а тип только в переменной типа integer!

   Тип перемещения (откуда перемещать указатель):

   0 - переместить указатель от начала файла, на указанно смещение
   1 - переместить указатель с текущей позиции, на указанно количество байт
   2 - переместить указатель с конца файла, на указанное количество байт

                                    * * *

  Запись строки в файл (команда "ftxt")

   Команда записывает строку в файл (аналог команды fprintf в си).

   Параметры команды совпадают с "write", только первым параметром должен
 идти файловый номер, а затем строка. Команда "write" выводит строку параметров
 на экран, а "ftxt" в файл.

   Даная команда очень удобна для ведения файлов отчетов.

                                    * * *

  Определение длины файла (команда "flength")

   Определяет длину ранее открытого файла (с указанным файловым номером), длина 
 будет лежать в переменной указанной компилятором.

   Пример использования: "flength(handle,size);"
   Команда определяет длину файла с файловым номером, хранящимся в переменной 
 "handle", длина будет лежать в переменной "size".

 ------------------------------------------------------------------------------

  Определение длины строки (команда "str_len")

   Команда определяет длину строки в переменной или по указанному смещению и 
 кладет размер в указанную переменную типа integer или real.

   Пример использования: "str_len(string,size);"
   Команда определяет длину строки хранящейся в переменной "string" и кладет 
 длину в переменную "size".

  Определить данные о пользователе в карточке (команда "define")

   Команда определяет параметры о пользователе, в базе данных.

   Сам интерпретатор не знает структуры базы, она определяется (точнее только 
 необходимые параметры пользователя) с помощью команды "define" в скрипте.

   Пример: "define usr_x [x,t]"

   Где: usr_x - имя, присеваемое этому полю карточки.
        x     - смещение от начала карточки
        t     - тип записи: 0 - integer, 1 - real, 2 - string

   Так же можно оперировать с полем byte (смотри команды byte_to_num и 
 int_to_byte)

   Примеры:
   "define usr_name [0,2];" - имя юзера (ascii-строка).
   "define user_msg [166,1];" - количество написаных писем (4 байта - real).
   "define user_priv [404,0];" - уровень доступа (2 байта - integer).

 * "define user_dob_day[390,0];" - день рождения (1 байт), полю размер которого
    1 байт, можно указать любой тип, оперировать с ним нужно только через
    специальные команды "byte_to_num" и "int_to_byte".

                                     * * *

  Глобальные команды работы с пользователями (rd_user, wr_user, dl_user)

   Команда читает (rd_user), записывает (wr_user) данные о указанном 
 пользователе или удаляет указанного пользователя из базы.

   Для того, что бы использовать эти команды, необходимо открыть базу и знать
 ее файловый номер (например "fopen("c:\max\user.bbs",base_handle);").

   У трех команд одинаковые параметры, файловый номер базы и номер пользователя
 (первый пользователь имеет номер 1, а не 0!)

   Пример использования: "rd_user(base_handle,10);"
   Прочитаем пользователя номер 10 из открытого файла (базы пользователей) с 
 файловым номером, хранящимся в переменной "base_handle".

                                     * * *

  Конвертор записи размером 1 байт (команда "byte_to_num")

   Команда переводит байт (из указанного смещения) в переменную типа integer  
 или real, для последующих операций с ним.

   Пример использования: integer num;
                         define dob_day[390,0];
                         byte_to_num(dob_day,num);

   День рождения текущего пользователя находится по смещению указанному в 
 "dob_day" и занимает один байт, он переводится в два байта (переменную типа
 integer) и кладется в переменную "num".

   Первый параметр команды (смещение) может быть указан только типом "параметр" 
 (тип задается командой "define").

                                     * * *

  Конвертор значения переменной типа integer в 1 байт (команда "int_to_byte")

   Команда переводит значение указанной переменной (только) типа integer в
 байт, затем кладет его по указанному смещению.

   Пример использования: integer day;
                         define dob_day[390,0];
                         int_to_byte(dob_day,num);

   Команда конвертирует значение переменной "num", типа integer (размер 2
 байта) в один байт и этот байт кладет в смещение указанное в параметре
 "dob_day".

   Первый параметр команды (смещение) может быть указан только типом "параметр" 
 (тип задается командой "define").

                                     * * *

  Конвертор значений структуры даты и времени (команда "date_to_num")

   Команда конвертирует указанные данные из указанной структуры (смещением), в 
 указанные переменные (указанного типа (real или integer)).

   Пример использования:
   string mo='xx';
   integer handle,da,yr;
   define user_last[192,0];
   string filename='user.bbs';
   fopen (filename,handle);        ; Читаем первого пользователя.
   rd_user(handle,1);
   date_to_num(user_last,da, ,yr); ; Переводим дату (кроме месяца) его
                                   ; последнего звонка в переменные типа integer
   yr=yr+1980;                     ; Конвертируем год, для вывода
   write('Дата последнего звонка: ',da,'/',mo,'/',yr);
   fclose (handle);
   pause;
   exit;
