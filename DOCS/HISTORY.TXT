 [-] - убрано

 [] - глобальное изменение
 [ ] - сообщение

                               История изменений


 20-NOVEMBER-2001       010/BETA
 ──────────────────────────────────────────────────────────────────────────────
 [*] Добавлен выход по ошибке, если при присвоении строка была неправильно
     закончена, либо вообще не закончена.
 [+] Добавлена возможность использовать подпрограммы.
 [*] Исправленая неточность в функции "file_length"
 [+] Добавлены команды для поиска в строке определенных символов, слов и т.д.
     "str(i)_find", команды могут применяться для поиска двойных логинов.
 [+] Добавлены: команда определения конца файла - "feof" и команда чтения одной
     строки из текстового файла - "fstr".
 [+] Добавлена возможность прервать выполнение скрипта нажатием клавиши ESC.


 13-NOVEMBER-2001       005/BETA
 ──────────────────────────────────────────────────────────────────────────────
 [+] В команду присвоения добавлен приоритет для умножения и деления.
 [+] Для преждевременного выхода из циклов "for", добавлена команда "break".
 [+] Добавлена команда "ftxt", позволяющая создавать файлы отчетов, о
     "проделанной работе". Эта команда аналог "write", но только выводит
     указанное не на экран, а в файл (по указанному файловому номеру).
 [*] Исправлена ошибка при загрузке (и присвоении им значений) в память
     нескольких переменных.
 [*] Изменен метод разбора команд и метод задания меток.
 [+] Добавлена возможность не указывать условие выхода из цикла "for" (для
     того, что бы можно было выйти в теле цикла).


 10-NOVEMBER-2001       001/BETA
