                            Maximus Script Language
          Скриптовый язык для работы с базой пользователей Maximus BBS

                   Copyright 2001 MOST NEEDFUL THINGS [MNT]


  О программе

   Данная программа предназначена для работы с базой пользователей Maximus BBS. 
 Цель программы  "автоматизировать" различные действия над пользователями и их
 параметрами в "системе", например проверить базу на наличие пользователей у
 которых сегодня день рождения и повысить им уровень доступа, стирать (например
 за редкие звонки), искать двойников, всячески поощрять за активные действия
 (написание писем, upload файлов и т.д) или составлять статистику "самых-самых"
 пользователей в различных категориях (upload, download, письма, звонки и т.д).

   Maximus Script Language это программа - компилятор, которая содержит 
 специальные команды для работы с базой пользователей Maximus BBS. Так же
 компилятор поддерживает ряд других простых команд. Язык представляет собой
 смесь "современных" высокоуровневых языков программирования, поэтому людям
 уже имеющим опыт в разработке программ на высокоуровневых языках (особенно
 си) будет достаточно просто разобраться с назначением команд, синтаксисом.


  Поддержка проекта

   Если вы нашли (по вашему мнению) ошибку при работе компилятора с (вашим) 
 скриптовым файлом, обязательно свяжитесь с нами (обязательно передайте нам
 скрипт который у вас неправильно работает).

   Любые свои положительные и отрицательные эмоции просьба слать нам. Их мы 
 попытаемся учесть в следующих версиях компилятора.

   www   : http://amethyst.nm.ru
   e-mail: needful_things@mail.ru


  Будущее проекта

   В дальнейшем мы планируем добавить в программу (или разработать отдельную 
 программу, которая будет дополнять компилятор) возможность вывода отчета
 работы скриптов в базу сообщений (Squish, JAM и т.д).

   Возможно, проект будет работать с базами пользователей под другие платформы 
 (кроме Maximus'а).
